# Privacy Policy

**Last Updated: November 15, 2025**

## 1. Introduction

FlowSync ("we", "our", "us") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our Service.

**By using FlowSync, you agree to the collection and use of information in accordance with this policy.**

## 2. Information We Collect

### 2.1 Information You Provide
- **Account Information**: Email address, name, timezone, password (encrypted)
- **Mood and Energy Data**: Text logs, energy levels, mood categories
- **Tasks and Goals**: Task descriptions, deadlines, priorities, tags
- **Preferences**: Theme settings, notification preferences, music preferences
- **Flow Blocks**: Session types, duration, completion data

### 2.2 Automatically Collected Information
- **Usage Data**: Features used, time spent, interaction patterns
- **Device Information**: Browser type, IP address, operating system
- **Performance Data**: App performance, error logs, crash reports
- **Analytics**: Page views, feature adoption, usage patterns

### 2.3 Information from Third-Party Services
- **Authentication**: OAuth data from social login providers (if applicable)
- **Music Services**: Spotify listening preferences (if connected)
- **Payment Information**: Payment processor data (Stripe/PayPal) for paid features

## 6. Data Storage and Security

### 6.1 Where We Store Data
- **Servers**: US-based cloud providers (AWS, Railway)
- **Backups**: Encrypted daily backups
- **CDN**: Vercel Edge Network (for frontend)

### 6.2 How We Protect Data
- **Encryption in Transit**: TLS 1.3 for all connections
- **Encryption at Rest**: AES-256 for stored data
- **Password Security**: Bcrypt hashing (cost factor 12)
- **Access Controls**: Role-based access, principle of least privilege
- **Regular Security Audits**: Automated and manual security testing
- **Secure Development**: Security-focused code review process

### 6.3 Data Retention
- **Active Accounts**: Data stored as long as account is active
- **Deleted Accounts**: Data deleted within 30 days
- **Legal Hold**: Data retained if required by law
- **Backups**: Deleted from backups within 90 days

## 8. Regional Privacy Rights

### 8.1 GDPR (European Union)
If you are in the EU/EEA, you have additional rights:
- **Right to Access**: Request copy of your data
- **Right to Rectification**: Correct inaccurate data
- **Right to Erasure**: "Right to be forgotten"
- **Right to Restriction**: Limit how we use your data
- **Right to Portability**: Receive data in machine-readable format
- **Right to Object**: Object to certain processing
- **Right to Withdraw Consent**: Withdraw consent anytime

**Legal Basis for Processing**:
- Consent: For optional features
- Contract: To provide the service
- Legitimate Interest**: To improve and secure the service

**Data Protection Officer**: dpo@flowsync.app

### 8.2 CCPA (California, USA)
If you are a California resident, you have rights to:
- Know what personal information is collected
- Know whether personal information is sold or disclosed
- Access your personal information
- Delete your personal information (with exceptions)
- Opt-out of sale (we don't sell data)
- Non-discrimination for exercising your rights

**To Exercise Rights**: privacy@flowsync.app
